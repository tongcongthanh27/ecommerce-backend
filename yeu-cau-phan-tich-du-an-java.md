Bạn hãy đóng vai Senior Java Backend Developer đồng thời là Technical Recruiter chuyên tuyển dụng Java Fresher/Junior tại các công ty công nghệ.

## Mục tiêu

Đọc và phân tích TOÀN BỘ source code của project hiện tại để xây dựng nội dung đưa vào CV ứng tuyển vị trí Java Fresher/Junior Backend Developer. Nội dung cần chuyên nghiệp, súc tích, đúng chuẩn CV IT, tập trung vào kỹ năng và kinh nghiệm thực tế thể hiện qua project, tương tự cách trình bày trong các CV Java Fresher chuyên nghiệp.

## Bước 1: Đọc toàn bộ project

Trước khi viết CV, hãy khảo sát toàn bộ repository, bao gồm:

* README, pom.xml và cấu hình application.
* Cấu trúc package, controller, service, repository, entity, DTO, mapper, exception, security, configuration.
* Các API đã triển khai và business logic tương ứng.
* Database schema, quan hệ giữa các entity, truy vấn JPQL/native query, Specification, phân trang, sắp xếp và lọc dữ liệu.
* Authentication, authorization, Spring Security, role-based access control.
* Validation, exception handling, transaction management và auditing.
* Các tích hợp bên ngoài như Cloudinary, email, thanh toán hoặc dịch vụ khác nếu có.
* Các tính năng liên quan đến sản phẩm, danh mục, biến thể sản phẩm, tồn kho, giỏ hàng, mã giảm giá, đơn hàng, thanh toán, vận chuyển, đánh giá, thông báo và phân quyền người dùng.
* Các bài toán tối ưu hiệu năng như N+1 query, fetch join, entity graph, truy vấn dữ liệu và xử lý transaction nếu thực sự có trong code.
* Các chức năng dành riêng cho Admin, User và Shipper.
* Unit test, integration test, Docker, CI/CD và deployment nếu repository có triển khai.

Hãy lần theo luồng xử lý từ Controller → Service → Repository → Database để hiểu chức năng thực tế. Đọc các file liên quan và kiểm tra code thay vì chỉ dựa vào tên class, tên API hoặc README.

## Bước 2: Phân loại mức độ hoàn thiện

Lập danh sách các tính năng và chia thành:

1. Đã triển khai và có bằng chứng rõ ràng trong code.
2. Đang triển khai hoặc mới hoàn thiện một phần.
3. Mới có cấu hình, ý tưởng hoặc chưa triển khai đầy đủ.

Chỉ sử dụng nhóm 1 làm thành tích chính trong CV. Với nhóm 2, chỉ đưa vào nếu diễn đạt rõ mức độ hoàn thành. Không mô tả nhóm 3 như kỹ năng hoặc chức năng đã hoàn thiện.

Không tự suy diễn rằng project đã chạy production, có người dùng thực tế, có CI/CD, có kiểm thử tự động hoặc đã tối ưu hiệu năng nếu không tìm thấy bằng chứng.

## Bước 3: Xác định công nghệ

Tổng hợp chính xác các công nghệ thực sự được sử dụng:

* Programming language.
* Backend framework và các module.
* ORM và database.
* Authentication/authorization.
* API design và validation.
* Build tools, version control, testing tools.
* External services, deployment và các công cụ hỗ trợ khác.

Phân biệt công nghệ đã sử dụng thực tế với dependency chỉ được khai báo nhưng chưa dùng.

## Bước 4: Viết nội dung CV

Từ kết quả phân tích, hãy tạo nội dung cho các phần sau:

### A. Project Name

Đặt tên project chuyên nghiệp, phù hợp với một hệ thống thương mại điện tử backend.

### B. Project Description

Viết 1–2 câu mô tả mục đích của hệ thống, đối tượng sử dụng và các nghiệp vụ chính.

### C. Tech Stack

Liệt kê các công nghệ quan trọng, ưu tiên Java, Spring Boot, Spring Security, Spring Data JPA/Hibernate, MySQL, RESTful API và các công nghệ khác thực sự được sử dụng.

### D. Responsibilities / Key Contributions

Viết 4–7 bullet point thể hiện những gì tôi trực tiếp phát triển hoặc có thể chứng minh qua code. Ưu tiên:

* Thiết kế và phát triển RESTful APIs.
* Xây dựng business logic và tổ chức kiến trúc Controller–Service–Repository.
* Thiết kế và thao tác với cơ sở dữ liệu quan hệ.
* Xử lý authentication, authorization và phân quyền theo vai trò.
* Triển khai nghiệp vụ thương mại điện tử.
* Xử lý validation, exception, transaction và các tình huống nghiệp vụ.
* Phân trang, tìm kiếm, lọc dữ liệu và tối ưu truy vấn nếu có bằng chứng.
* Tích hợp dịch vụ bên ngoài nếu thực sự đã hoàn thiện.

Mỗi bullet nên bắt đầu bằng động từ mạnh như Developed, Implemented, Designed, Integrated, Optimized hoặc Secured nếu viết tiếng Anh.

Mỗi bullet cần thể hiện rõ:

* Tôi đã làm gì.
* Sử dụng công nghệ hoặc kỹ thuật nào.
* Giải quyết vấn đề nghiệp vụ gì hoặc đem lại lợi ích gì.

Không viết chung chung kiểu “Responsible for backend development” hoặc liệt kê một loạt công nghệ mà không thể hiện cách sử dụng.

### E. Technical Highlights

Chọn 3–5 điểm kỹ thuật đáng giá nhất để nhà tuyển dụng hỏi sâu khi phỏng vấn. Giải thích ngắn gọn cách hoạt động và vị trí code chứng minh từng điểm.

### F. Skills có thể đưa vào CV

Phân nhóm:

* Programming Languages.
* Backend Technologies.
* Database.
* Tools.
* Concepts.

Chỉ đưa những kỹ năng có bằng chứng từ project hoặc được xác nhận rõ ràng. Không tự đánh giá trình độ thành thạo dựa trên việc chỉ xuất hiện một lần trong source code.

## Bước 5: Tối ưu cho vị trí Java Fresher

Ưu tiên chất lượng hơn số lượng. Nhà tuyển dụng cần nhìn thấy khả năng viết Java, hiểu OOP, xây dựng REST API, làm việc với database, tổ chức code theo layer và giải quyết business logic.

Không biến project thành danh sách tất cả các API. Hãy chọn những đóng góp thể hiện năng lực backend rõ nhất.

Không bịa số lượng người dùng, số lượng API, phần trăm cải thiện hiệu năng, số lượng dữ liệu, thành tích định lượng hoặc kết quả kinh doanh. Nếu muốn đưa số liệu, hãy đếm từ source code hoặc cung cấp bằng chứng kiểm chứng được và ghi rõ phạm vi.

## Bước 6: Đầu ra

Trả về theo đúng thứ tự:

1. **Tổng quan project:** mục đích, kiến trúc, công nghệ.
2. **Các tính năng đã hoàn thành:** kèm đường dẫn file quan trọng để kiểm chứng.
3. **Nội dung CV tiếng Anh:** một phiên bản hoàn chỉnh, súc tích, có thể copy trực tiếp vào CV.
4. **Nội dung CV tiếng Việt:** bản tương đương để tôi đối chiếu.
5. **Technical highlights:** các điểm mạnh có thể dùng khi phỏng vấn.
6. **Danh sách kỹ năng nên ghi trong CV:** chia theo nhóm.
7. **Những nội dung chưa đủ bằng chứng:** các kỹ năng hoặc chức năng không nên ghi là đã hoàn thành.
8. **Câu hỏi phỏng vấn có thể phát sinh:** dựa trực tiếp trên code của project, kèm gợi ý nội dung cần nắm vững.

Đối với phần CV tiếng Anh, hãy giữ văn phong chuyên nghiệp, sử dụng các bullet ngắn gọn, ưu tiên kết quả và kỹ thuật, tránh câu dài. Mục tiêu là nội dung phù hợp với một project cá nhân hoặc academic project của ứng viên Java Fresher, không phóng đại kinh nghiệm như một Senior Developer.

## Nguyên tắc bắt buộc

* Đọc code trước khi đưa ra kết luận.
* Không sửa đổi, xóa hoặc tạo file trong project.
* Không tự động refactor code.
* Không tự bịa thông tin cá nhân, thời gian thực hiện, quy mô nhóm hoặc phần trăm đóng góp.
* Nếu không xác định được phần nào do tôi trực tiếp làm, hãy ghi rõ điểm chưa xác định và yêu cầu tôi xác nhận trước khi sử dụng trong CV.
* Khi nhận định một tính năng hoặc kỹ thuật đã triển khai, hãy chỉ ra đường dẫn file và bằng chứng liên quan.
* Không dừng lại sau khi đọc README hoặc một vài class đại diện. Hãy khảo sát toàn bộ repository trước khi hoàn thành báo cáo.

Bây giờ hãy bắt đầu bằng việc kiểm tra cấu trúc repository, sau đó phân tích source code và hoàn thành các đầu ra trên. Không thay đổi bất kỳ file nào.
